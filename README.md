# Nome do Projeto
Confiro já 

## Descrição
Este projeto tem como objetivo desenvolver um software que seja capaz de registrar produtos,remover, editar a quantidade, ser acessível para pessoas com alguma limitação visual e fazer a análise das movimentações realizadas.

## Objetivo
O objetivo deste projeto e fornecer um meio mais prático e mais eficaz para fazer o registro e controle do estoque.

## Funcionalidades previstas 
- Cadastrar item
- Inserir e remover item
- Status / sem estoque - aguardando retirada
- Estatísticas / média de quantidade utilizada / mês - semana
- Qualidade do lote
- Projeção de quantidade necessária
